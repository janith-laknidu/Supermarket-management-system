# Supermarket Management System

A console-based supermarket management system developed using the C programming language. This project helps manage supermarket operations such as product handling, stock control, customer services, and billing through a menu-driven interface.

---

## Features

### Employee Section

* Product Management

  * Add Products
  * View Products
  * Search Products
  * Update Products
  * Delete Products

* Stock Management

  * Manage Product Stock
  * Update Quantities
  * Check Available Stock

* Reports

  * Generate Product Reports
  * Display Stock Details
  * View System Information

---

### Customer Section

* View Products
* Search Products
* View Prices
* Billing System

---

## How to Run

1. Open the project in VS Code
2. Compile all `.c` files

Example:


gcc *.c -o supermarket


3. Run the program

./supermarket
